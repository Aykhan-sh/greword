# GREWord

Offline GRE vocabulary flashcards with spaced repetition (FSRS-6), as a web app that
installs on an iPhone.

## Install on an iPhone

1. Open the site in **Safari**.
2. Tap **Share**, then **Add to Home Screen**.
3. Open GREWord from the home-screen icon. After the first load it works offline.

Progress is stored on the phone only, inside the installed app. Use Settings → Export to
keep a backup; the file also imports into the Android version.

## How to use it

A card shows the word. Tap anywhere to see the meaning, then swipe **right if you knew
it** and **left if you didn't**. The back arrow undoes a mis-swipe. How long you took
before tapping decides how strongly a correct answer counts.

Word origins come from Wiktionary (CC BY-SA 4.0). Pronunciation uses the device's
built-in voice.
